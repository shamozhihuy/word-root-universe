# 词根宇宙 · 多语料库

一个本地优先、多词库、多模态的英语词汇学习 Web 应用。

## 主要功能

- 多词库隔离：小学、初中、高中、A 级、四级、六级、考研、雅思、托福、常用、自定义词库
- 词根画廊与跨词库同根词查询
- 单词预览：英文、音标、中文释义与在线标准发音
- 沉浸式默写、听音选义、跟读训练
- 首次能力测试与 AI 私人老师
- 专属训练：按固定顺序完成认词、听音、默写和口语输出
- 学习顺序持久化：关闭网站后继续停留在上次学习的单词
- 序号查词：搜索栏输入数字可直接定位到当前顺序中的第几个词
- 训练检测：完成专属训练后可进入检测，并决定是否进入下一轮训练
- 艾宾浩斯遗忘曲线复习与错题自动归类
- 自动发音开关：进入新单词时自动播放标准音频
- 手机版、电脑版、自动适应视图切换
- 支持 CSV、TXT、JSON、图片导入导出
- 学习数据默认保存在浏览器本地

## 快速开始

直接打开 `index.html`，或运行：

```bash
npx serve .
```

## 使用说明

1. 首次进入先完成能力测试
2. AI 功能需要在设置里填写 OpenAI 或 DeepSeek API Key
3. 跟读训练需要允许浏览器麦克风权限
4. 当前版本学习记录保存在当前浏览器
5. 词库穿越默认隐藏，可在设置中开启
