# 词根宇宙 · 多语料库

一个本地优先、多词库、多模态的英语词汇学习 Web 应用。

## 主要功能

- 多词库隔离：A 级、四级、考研、雅思、托福、自定义词库
- 词根画廊与跨词库同根词查询
- 沉浸式默写、听音选义、跟读训练
- 首次能力测试与 AI 私人老师
- 艾宾浩斯遗忘曲线复习与错题自动归类
- 支持 CSV、TXT、JSON、图片导入导出
- 学习数据默认保存在浏览器本地

## 快速开始

直接打开 `index.html`，或运行：

```bash
npx serve .
```

## 使用说明

1. 首次进入先完成能力测试
2. AI 功能需要在设置里填写 OpenAI 或 DeepSeek API Key
3. 跟读训练需要允许浏览器麦克风权限
4. 当前版本学习记录保存在当前浏览器

## 项目结构

```text
index.html  主界面
vocab.js    词库数据与核心逻辑
```

## 数据来源

内置词库参考或基于 `KyleBing/english-vocabulary`。
